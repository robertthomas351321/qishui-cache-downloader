# qishui-cache-downloader

此工具可以用来下载vip音乐

你在电脑上打开汽水音乐，把你想要下的歌点开听一下。不用整首听完，只要音乐响起来两三秒就行，因为只要一响，软件就已经把最高音质的下载地址和解密钥匙全写进你电脑缓存里了。

听完之后，到这个文件夹里，直接双击运行“点我启动_音乐解析下载.bat”。

黑框弹出来后会自动把你刚才听过的歌全列出来，前面都有序号。你想要下哪首，就直接输入对应的数字按回车。想一次下好几首，中间用空格或者逗号隔开就行，比如想下第1、3、5首，就打“1 3 5”。如果你觉得列表里的全都要，直接打个“all”按回车。

选完歌它会问你音质，直接敲回车或者选1就行，默认就是选最高音质。这首歌有无损flac就会直接下无损，没有无损就下最好的aac。解密出来是什么文件就是什么文件，不会自作聪明帮你转成mp3掉音质，后缀也不会乱改。

下好的文件全都在这个文件夹里的downloads目录里。

另外注意一件事：下载链接是有有效期的，大概几个小时。如果你今天想下一首前几天听过的老歌，下载时可能会提示超时或失败，那纯粹是因为下载链接过期了。遇到这种情况不用慌，回到汽水音乐里找到那首歌重新点开放两秒钟，然后再跑一次这个脚本就能正常下了。以后只要听了新歌想存本地，随时双击这个bat就行。
